# FamTree

作成・メンテナンス：**[john3sobieski](https://github.com/john3sobieski)**。リポジトリ：<https://github.com/john3sobieski/family-tree>

家系図の作成、編集、閲覧ができる Windows 用デスクトップアプリです。人物、関係、すべての写真が、1 つの `.famtree` ファイルにまとまります。

> **ステータス：** 開発初期段階です。インストーラーは [Releases](https://github.com/john3sobieski/family-tree/releases) からダウンロードできます（[インストール](#インストール)を参照）。

## 機能

- **3 つのモード**
  - **閲覧**（*View*）– 滑らかなズームとパンができる、読み取り専用のマインドマップ。
  - **編集**（*Edit*）– 人物、写真、関係の追加と変更。
  - **リスト**（*List*）– 家系図に含まれる全員を、並べ替え・絞り込みできる表で表示。
- **自分を中心に描かれるマインドマップ。** 1 人を「自分」に指定すると、いちばん上の先祖から下に向かって家系図が描かれ、両親、きょうだい、おじ・おば、いとこ、さらに遠い親戚まで自動的に表示されます。父方と母方の家系は並べて配置され、姻戚の家系も含まれます。
- **写真付きカード。** 各カードには、証明写真風の写真、名前、姓（女性は括弧内に旧姓）、父称、性別を示す色のライン、最大 2 つの国籍の旗が表示されます。
- **人物ウィンドウ。** カードをクリックすると、大きな写真、ギャラリー（1 人あたり 10 枚以上でも問題なし）、日付、年齢、出生地・死亡地、職業、メモ、そして両親・パートナー・子へのクリックできるリンクを備えた大きなウィンドウが開きます。
- **検索。** 名前を入力すると、カメラがマップ上のその人物まで移動してハイライトします。リストモードではフィルターとして機能します。`Ctrl+F` で検索欄にフォーカスできます。
- **関係。** 両親、パートナー、子、きょうだいは、ワンクリックで追加することも、すでに存在する人物にリンクすることもできます。循環や重複したリンクは拒否されます。
- **不完全な日付。** 年しか分からない場合も大丈夫です。日付のどの部分も空欄にできます。
- **国籍。** 内蔵の 197 か国のリスト（国連加盟国すべてとバチカン、パレスチナ、台湾、コソボ）から、1 人につき最大 2 つまで選べます。国旗はアプリ自身が描画します。
- **大規模な家系図にも対応。** 見えているカードだけを描画し、サムネイルは遅延読み込みされ、レイアウトは構造が変わったときにのみ再計算されます。数千人規模の家系図でテスト済みです。
- **自動保存。** 家系図にファイルが関連付けられていれば、入力が止まった少し後に、変更が自動的に保存されます。新規の家系図は、まず**名前を付けて保存…**（*Save as…*）を使ってください。保存できていないものがある場合は、閉じる前に確認されます。
- **インターフェースの言語。** Русский、English、中文、Español、Français、Deutsch、Polski に対応しています。**Language** メニューで切り替えでき、選択は記憶されます。初回起動時は Windows の表示言語に従い、対応していない言語の場合は英語になります。国名も翻訳されます。
- **エクスポート。** **File → Export…** で、ツリー全体を PNG またはベクター PDF として余白付きで保存できます。PNG では背景（透明・白・黒）とダーク/ライトの配色を選べ、サイズは鮮明さを保つよう自動で決まります（最大 ×2）。PDF は画質を落とさず拡大できます。非常に大きなツリーは PDF での書き出しがおすすめです。
- **ダブルクリックで開く。** **ファイル**（*File*）メニューで、`.famtree` ファイルをアプリに関連付けられます。
- **ダークテーマとライトテーマ。** ステータスバー右端の太陽/月ボタンで切り替えます。選択は記憶されます。

## インストール

Windows 10 と Windows 11 の両方で動作します。インストーラーも exe も両方で同じものです。

1. [Releases](https://github.com/john3sobieski/family-tree/releases) ページを開き、**`FamTree-Setup-<バージョン>.exe`** をダウンロードします。
2. 実行します。インストールは現在のユーザー専用なので、管理者権限は不要です。ウィザードで、`.famtree` ファイルを FamTree で開く設定とデスクトップのショートカットを選べます。
3. スタートメニューから **FamTree** を起動します。

補足：

- インストーラーと `.exe` が署名されていないため、Windows が SmartScreen の警告を表示することがあります。*詳細情報 → 実行* を選んでください。
- 更新するには、新しい Setup を古いバージョンの上から実行します。家系図と設定は保持されます。
- アンインストールは *設定 → アプリ* から行います。`.famtree` ファイルが削除されることはありません。
- ポータブル版の exe を使っていて移動した場合は、**ファイル**メニューの `.famtree` 関連付けボタンをもう一度押してください。

### 自分でビルドする

ツールをインストールしなくても、GitHub Actions からインストーラーを入手できます（GitHub アカウントが必要です）。[リポジトリ](https://github.com/john3sobieski/family-tree)を Fork し、**Actions → Build → Run workflow** を実行して、完了した実行から **`famtree-setup`** アーティファクトをダウンロードします（デフォルトで 90 日間保持されます）。

## クイックスタート

1. `famtree.exe` を起動します。**ファイル → デモ**（*File → Demo*）でサンプルの家系図を見るか、**ファイル → 新規**（*File → New*）で自分の家系図を始めます。
2. **編集**モードに切り替えて、最初の人物を追加します（*＋ New person*）。空の家系図では、その人物が自動的に「自分」になります。
3. 人物を選択し、**＋ 親**、**＋ パートナー**、**＋ 子**、**＋ きょうだい**（*＋ Parent*、*＋ Partner*、*＋ Child*、*＋ Sibling*）を使って家系図を広げていきます。右側で名前、日付、写真、メモを入力します。
4. **名前を付けて保存…**を選んで名前を付けます。それ以降、変更は自動的に保存されます。
5. **閲覧**に切り替えてマップを見て回ります。ドラッグでパン、スクロールでズーム、**全体表示**（*Fit to view*）ですべてを表示、カードをクリックで詳細を表示できます。

## `.famtree` ファイル

`.famtree` ファイルは、ごく普通の ZIP アーカイブです。

```
tree.json            people and relationships (plain, human-readable text)
media/<hash>.jpg     photos, resized to at most 1600 px
thumb/<hash>.jpg     small thumbnails for cards
```

- 写真はファイルの中に保存されるので、1 つの `.famtree` を親戚に送っても何も失われません。同一の写真は 1 回だけ保存されます。
- `tree.json` はどんなテキストエディタでも読め、各関係を説明するコメントが付いています。手動で編集したい場合は、アーカイブを展開してファイルを編集し、再びまとめてください。`.famtree` の中で直接編集するとアーカイブが壊れます。
- 古いファイルも、新しいバージョンのアプリで開き続けられます。

## 既知の制限

- ロシア語以外のインターフェース翻訳は、まだネイティブスピーカーによる確認を受けていません。修正はイシューで歓迎します。
- 日付は言語に関係なく、常に `DD.MM.YYYY` 形式で表示されます。
- 元に戻す機能はまだありません。
- 大量の写真を一度にインポートすると、ウィンドウが一瞬固まることがあります。
- HEIC 写真は非対応です（JPEG、PNG、WebP、BMP には対応）。
- カードのサムネイルは中央でのトリミングで、トリミング範囲はまだ選べません。
- 非常に大きな家族では、人物が不自然な位置に配置されたり、枝同士の線が交差したりすることがあります（ロードマップを参照）。
- 国籍はリストモードでは表示されません。

## ソースからのビルド

ローカルでビルドしたい場合は、Windows に Rust ツールチェーンが必要です。

```
cargo test --release
cargo build --release
```

成果物は `target/release/famtree.exe` です。このプロジェクトでは、インターフェースに [egui/eframe](https://github.com/emilk/egui) を使用しています。

## バグ報告

問題を見つけましたか？特にマップ上の人物の配置についてであれば、[issue を作成](https://github.com/john3sobieski/family-tree/issues)してください。可能であれば、問題を再現できる小さな `.famtree` ファイルを添付してください（家系図が非公開の場合は、実在の個人情報を含めないでください）。
