## Цель
Простое десктопное приложение на Rust (Windows 10): создавать, редактировать и отображать семейное дерево. Сохранение/открытие в формате `.famtree`. Дизайн отдан мне.

## Требования пользователя
- Платформа: **Windows 10**.
- У людей есть **фото**; в заметках **много фото (10+)**; все фото лежат **внутри `.famtree`**.
- **3 режима**:
  1. **Просмотр** — только чтение, zoom/pan по ветвям.
  2. **Редакция** — добавление/изменение всех данных.
  3. **Список** — просмотр списком (не mindmap).
- Mindmap: от родителей пользователя вниз. Включает дальних родственников (сёстры, кузены, троюродные и т.д.).
- **Масштаб**: много людей и данных, должно работать плавно.
- **Карточка в дереве**: только фото (как на паспорт) + имя и фамилия снизу.
- **Клик по карточке** → большое окно: остальная информация (специальность, возраст, фото и т.д.).
- **Поиск** по имени: в Mindmap камера плавно перелетает (pan+zoom) к найденному человеку и подсвечивает его. В списке — фильтр.
- Корень дерева (`Tree::root`) — **сам пользователь («я»)**. Схема строится автоматически от его верхних предков вниз (родители, братья/сёстры, дяди, кузены видны). Предки с двух сторон — два дерева рядом.
- Экспорт PNG/PDF — **в самом конце**, после готового приложения. Не мешать архитектуре (держать отрисовку отделимой).

## Решения
- Выпуск: итоговый **.exe**, сборка только в **GitHub Actions**.
- GUI: `eframe`/`egui`.
- Формат `.famtree` = **ZIP-контейнер**: `tree.json` (данные, поле `version`) + `media/<sha256>.jpg` (фото). Крейты: `zip`, `serde`, `serde_json`, `image`, `sha2`.
- Фото: при импорте масштабировать (полное ≤ ~1600px, миниатюра для карточки ~200px, JPEG), дедупликация по хэшу.
- Производительность: раскладка считается один раз/при изменениях; рисовать только видимые карточки (culling); текстуры миниатюр грузить лениво + кэш с лимитом; полные фото — только в окне человека.
- Сохранение атомарное (temp-файл → rename).
- Диалоги: `rfd`. Открытие двойным кликом: путь в `std::env::args()`.
- Ассоциация `.famtree` на Windows: реестр `HKCU\Software\Classes` (без админа), позже.
- Модули: `model` / `io` / `media` / `layout` / `ui` (view, edit, list, person_window).

## Модель данных (черновик)
- `Person { id, имя, фамилия, пол, рождение, смерть, специальность, заметки, photo_main, photos[] }`
- `Relation`: родитель→ребёнок (допустимо несколько родителей), партнёры (+даты)
- `Tree { version, root_id, persons, relations, media_index }`
