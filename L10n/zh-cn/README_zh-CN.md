# FamTree

作者与维护者：**[john3sobieski](https://github.com/john3sobieski)**。仓库地址：<https://github.com/john3sobieski/family-tree>

一款用于创建、编辑和浏览家谱的 Windows 桌面应用。所有内容都保存在单个 `.famtree` 文件中：人物、关系以及全部照片。

> **状态：** 早期开发阶段。目前没有现成的发行版，只能通过 GitHub Actions 自行构建来获得应用（见[安装](#安装)）。界面暂时只有俄语（见[路线图](#路线图)）。

## 功能

- **三种模式**
  - **查看**（*Просмотр*）– 只读的思维导图，支持平滑缩放和平移。
  - **编辑**（*Редакция*）– 添加和修改人物、照片与关系。
  - **列表**（*Список*）– 可排序、可筛选的全体人物表格。
- **以你为中心的思维导图。** 将某个人标记为"我"，家谱就会从你最上层的祖先向下绘制，因此父母、兄弟姐妹、叔伯姑姨、堂表兄弟姐妹以及更远的亲属都会自动显示。父系和母系并排排布，姻亲家庭也会一并纳入。
- **照片卡片。** 每张卡片显示证件照风格的照片、名字、姓氏（女性的娘家姓写在括号里）、父称、表示性别的色条，以及最多两面国籍旗帜。
- **人物窗口。** 点击卡片会打开更大的窗口，包含完整照片、相册（每人 10 张以上照片没问题）、日期、年龄、出生地和逝世地、职业、备注，以及可点击跳转的父母、伴侣和子女链接。
- **搜索。** 输入名字后，镜头会飞到该人物所在位置并将其高亮。在列表模式下则作为筛选器使用。`Ctrl+F` 可聚焦搜索框。
- **关系。** 父母、伴侣、子女和兄弟姐妹可以一键添加，也可以关联到已有的人物。循环关系和重复关联会被拒绝。
- **不完整日期。** 只知道年份？没问题，日期的任何部分都可以留空。
- **国籍。** 每人最多可从内置的 47 个国家列表中选择两个（46 个欧洲国家加尼日利亚）。国旗由应用自行绘制。
- **为大型家谱而生。** 只绘制可见的卡片，缩略图延迟加载，只有结构变化时才重新计算布局。已在数千人规模的家谱上测试过。
- **自动保存。** 家谱一旦有了文件，停止输入片刻后每次修改都会自动保存。新建的家谱请先使用**另存为…**（*Сохранить как…*）。如果有内容未能保存，关闭前也会提示你。
- **双击打开。** 在**文件**（*Файл*）菜单中可以将 `.famtree` 文件与应用关联。

## 安装

目前应用仅支持 Windows 10，并由 GitHub Actions 从源码构建，因此你的电脑上不需要安装 Rust 或其他工具。但你需要一个 GitHub 账号。

1. **Fork** [仓库](https://github.com/john3sobieski/family-tree)（或使用你自己的副本）。
2. 在你的 fork 中打开 **Actions** 标签页。如果 GitHub 提示，请为该 fork 启用工作流。
3. 选择 **Build** 工作流，点击 **Run workflow**，等待其完成（约 2–3 分钟）。每次 push 时它也会自动运行。
4. 打开已完成的运行记录，在底部的 *Artifacts* 区域下载 **`famtree-windows`** 产物。
5. 解压。里面是 `famtree.exe`。无需安装，直接运行即可。

注意事项：

- 由于 `.exe` 未签名，Windows 可能会显示 SmartScreen 警告。如果你信任自己构建的程序，请选择*更多信息 → 仍要运行*。
- GitHub 对产物的保留时间有限（默认 90 天），请把 `.exe` 保存到长期存放的位置。
- 如果移动了 `famtree.exe`，请再次点击**文件**菜单中的 `.famtree` 关联按钮，因为关联指向的是 exe 的位置。

正式的安装程序出现后，将发布在 **Releases** 中，本节也会随之替换。

## 快速上手

1. 启动 `famtree.exe`。使用 **文件 → 演示**（*Файл → Демо*）查看示例家谱，或使用 **文件 → 新建**（*Файл → Новое*）开始你自己的家谱。
2. 切换到**编辑**模式，添加第一个人物（*＋ Новый человек*）。在空家谱中，此人会自动成为"我"。
3. 选中一个人，使用 **＋ 父母**、**＋ 伴侣**、**＋ 子女** 或 **＋ 兄弟姐妹**（*＋ Родитель*、*＋ Партнёр*、*＋ Ребёнок*、*＋ Брат/сестра*）来扩展家谱。在右侧填写姓名、日期、照片和备注。
4. 选择**另存为…**并取一个名字。此后，修改会自动保存。
5. 切换到**查看**来浏览导图：拖动平移，滚轮缩放，**适应窗口**（*По размеру*）可查看全部内容，点击卡片查看详情。

## `.famtree` 文件

`.famtree` 文件就是一个普通的 ZIP 压缩包：

```
tree.json            people and relationships (plain, human-readable text)
media/<hash>.jpg     photos, resized to at most 1600 px
thumb/<hash>.jpg     small thumbnails for cards
```

- 照片存放在文件内部，所以你可以把一个 `.famtree` 发给亲戚而不会丢失任何内容。相同的照片只会存储一次。
- `tree.json` 可以用任何文本编辑器打开，并带有说明各个关系的注释。如果想手动编辑，请先解压压缩包，编辑文件后再重新打包。直接在 `.famtree` 内部编辑会破坏压缩包。
- 旧文件可以在新版本的应用中继续打开。

## 已知限制

- 界面目前只有俄语。
- 仅支持 Windows 10。
- 暂无撤销功能，也不支持导出为 PNG/PDF。
- 一次性导入大量照片时，窗口可能会短暂卡住。
- 不支持 HEIC 照片（支持 JPEG、PNG、WebP 和 BMP）。
- 卡片上的缩略图是居中裁剪，暂时无法选择裁剪区域。
- 在非常大的家族中，布局仍可能把人物放到奇怪的位置，或使不同分支之间的连线交叉（见路线图）。
- 列表模式下不显示国籍。

## 从源码构建

如果你想在本地构建，需要在 Windows 上安装 Rust 工具链：

```
cargo test --release
cargo build --release
```

产物位于 `target/release/famtree.exe`。该项目的界面使用 [egui/eframe](https://github.com/emilk/egui)。
