# FamTree

제작 및 유지보수: **[john3sobieski](https://github.com/john3sobieski)**. 저장소: <https://github.com/john3sobieski/family-tree>

가계도를 만들고, 편집하고, 둘러볼 수 있는 Windows 데스크톱 앱입니다. 사람, 관계, 모든 사진이 하나의 `.famtree` 파일에 담깁니다.

> **상태:** 초기 개발 단계입니다. 설치 프로그램은 [Releases](https://github.com/john3sobieski/family-tree/releases)에서 받을 수 있습니다([설치](#설치) 참고).

## 기능

- **세 가지 모드**
  - **보기**(*View*) – 부드러운 확대/축소와 이동이 가능한 읽기 전용 마인드맵.
  - **편집**(*Edit*) – 사람, 사진, 관계를 추가하고 수정합니다.
  - **목록**(*List*) – 가계도에 있는 모든 사람을 정렬하고 필터링할 수 있는 표.
- **나를 중심으로 그려지는 마인드맵.** 한 사람을 "나"로 지정하면 가장 위의 조상부터 아래로 가계도가 그려지므로, 부모, 형제자매, 삼촌·이모·고모, 사촌, 더 먼 친척까지 자동으로 표시됩니다. 양쪽 집안이 나란히 배치되며, 인척 가족도 포함됩니다.
- **사진 카드.** 각 카드에는 증명사진 스타일의 사진, 이름, 성(여성은 괄호 안에 결혼 전 성), 부칭, 성별을 나타내는 색 띠, 최대 두 개의 국적 국기가 표시됩니다.
- **인물 창.** 카드를 클릭하면 전체 사진, 갤러리(한 사람당 사진 10장 이상도 문제없음), 날짜, 나이, 출생지와 사망지, 직업, 메모, 그리고 부모·배우자/파트너·자녀로 이동하는 클릭 가능한 링크가 있는 더 큰 창이 열립니다.
- **검색.** 이름을 입력하면 카메라가 지도에서 해당 인물로 이동하고 강조 표시합니다. 목록 모드에서는 필터로 작동합니다. `Ctrl+F`로 검색창에 포커스를 둘 수 있습니다.
- **관계.** 부모, 파트너, 자녀, 형제자매는 한 번의 클릭으로 추가하거나 이미 있는 사람과 연결할 수 있습니다. 순환 관계와 중복 연결은 거부됩니다.
- **불완전한 날짜.** 연도만 알고 있나요? 괜찮습니다. 날짜의 어떤 부분이든 비워 둘 수 있습니다.
- **국적.** 내장된 197개국 목록(유엔 회원국 전체와 바티칸, 팔레스타인, 대만, 코소보)에서 한 사람당 최대 두 개까지 고를 수 있습니다. 국기는 앱이 직접 그립니다.
- **대규모 가계도를 위한 설계.** 보이는 카드만 그리고, 썸네일은 지연 로딩하며, 레이아웃은 구조가 바뀔 때만 다시 계산합니다. 수천 명 규모의 가계도로 테스트했습니다.
- **자동 저장.** 가계도에 파일이 생기면, 입력을 멈춘 직후 모든 변경 사항이 자동으로 저장됩니다. 새 가계도는 먼저 **다른 이름으로 저장…**(*Save as…*)을 사용하세요. 저장하지 못한 내용이 있으면 닫기 전에 확인도 합니다.
- **인터페이스 언어.** Русский, English, 中文, Español, Français, Deutsch, Polski를 지원합니다. **Language** 메뉴에서 전환할 수 있으며 선택한 언어는 기억됩니다. 처음 실행할 때는 Windows 표시 언어를 따르고, 지원하지 않는 언어이면 영어를 사용합니다. 국가 이름도 번역됩니다.
- **더블클릭으로 열기.** **파일**(*File*) 메뉴에서 `.famtree` 파일을 앱에 연결할 수 있습니다.

## 설치

앱은 Windows 10과 Windows 11에서 동작합니다. 두 버전 모두 같은 설치 프로그램과 같은 exe를 사용합니다.

1. [Releases](https://github.com/john3sobieski/family-tree/releases) 페이지를 열고 **`FamTree-Setup-<버전>.exe`**를 다운로드합니다.
2. 실행합니다. 현재 사용자에게만 설치되므로 관리자 권한이 필요 없습니다. 마법사에서 `.famtree` 파일을 FamTree로 열도록 연결하고 바탕 화면 바로 가기를 추가할 수 있습니다.
3. 시작 메뉴에서 **FamTree**를 실행합니다.

참고:

- 설치 프로그램과 `.exe`가 서명되지 않았기 때문에 Windows에서 SmartScreen 경고가 표시될 수 있습니다. *추가 정보 → 실행*을 선택하세요.
- 업데이트하려면 새 Setup을 이전 버전 위에 실행하세요. 가계도와 설정은 유지됩니다.
- 제거는 *설정 → 앱*에서 합니다. `.famtree` 파일은 삭제되지 않습니다.
- 포터블 exe를 사용하다가 옮겼다면 **파일** 메뉴의 `.famtree` 연결 버튼을 다시 누르세요.

### 직접 빌드하기

도구를 설치하지 않고도 GitHub Actions에서 설치 프로그램을 받을 수 있습니다(GitHub 계정 필요). [저장소](https://github.com/john3sobieski/family-tree)를 Fork하고 **Actions → Build → Run workflow**를 실행한 뒤, 완료된 실행에서 **`famtree-setup`** 아티팩트를 다운로드합니다(기본 90일간 보관).

## 빠른 시작

1. `famtree.exe`를 실행합니다. **파일 → 데모**(*File → Demo*)로 샘플 가계도를 보거나, **파일 → 새로 만들기**(*File → New*)로 나만의 가계도를 시작합니다.
2. **편집** 모드로 전환하고 첫 번째 사람을 추가합니다(*＋ New person*). 빈 가계도에서는 그 사람이 자동으로 "나"가 됩니다.
3. 사람을 선택하고 **＋ 부모**, **＋ 파트너**, **＋ 자녀**, **＋ 형제자매**(*＋ Parent*, *＋ Partner*, *＋ Child*, *＋ Sibling*)를 사용해 가계도를 넓혀 갑니다. 이름, 날짜, 사진, 메모는 오른쪽에서 입력합니다.
4. **다른 이름으로 저장…**을 선택하고 이름을 정합니다. 그 이후로는 변경 사항이 자동으로 저장됩니다.
5. **보기**로 전환해 지도를 둘러보세요. 드래그로 이동, 스크롤로 확대/축소, **전체 보기**(*Fit to view*)로 모두 보기, 카드를 클릭하면 자세한 정보를 볼 수 있습니다.

## `.famtree` 파일

`.famtree` 파일은 평범한 ZIP 압축 파일입니다.

```
tree.json            people and relationships (plain, human-readable text)
media/<hash>.jpg     photos, resized to at most 1600 px
thumb/<hash>.jpg     small thumbnails for cards
```

- 사진은 파일 안에 저장되므로, `.famtree` 파일 하나만 친척에게 보내도 아무것도 잃지 않습니다. 동일한 사진은 한 번만 저장됩니다.
- `tree.json`은 어떤 텍스트 편집기로도 읽을 수 있으며, 각 관계를 설명하는 주석이 들어 있습니다. 직접 편집하려면 압축을 풀고, 파일을 수정한 뒤 다시 압축하세요. `.famtree` 내부에서 바로 편집하면 압축 파일이 손상됩니다.
- 이전 버전의 파일도 새 버전 앱에서 계속 열 수 있습니다.

## 알려진 제한 사항

- 러시아어를 제외한 인터페이스 번역은 아직 원어민의 검수를 받지 않았습니다. 수정 제안은 이슈로 환영합니다.
- 날짜는 언어와 관계없이 항상 `DD.MM.YYYY` 형식으로 표시됩니다.
- 실행 취소와 PNG/PDF 내보내기는 아직 없습니다.
- 많은 사진을 한꺼번에 가져오면 창이 잠시 멈출 수 있습니다.
- HEIC 사진은 지원되지 않습니다(JPEG, PNG, WebP, BMP는 지원).
- 카드의 썸네일은 가운데를 기준으로 자른 것이며, 자르는 영역은 아직 선택할 수 없습니다.
- 규모가 매우 큰 가족에서는 레이아웃이 사람을 엉뚱한 위치에 배치하거나 가지 사이의 선이 교차할 수 있습니다(로드맵 참고).
- 국적은 목록 모드에 표시되지 않습니다.

## 로드맵

계획 중인 개선 사항입니다(순서 무관).

- [ ] **레이아웃 버그 수정**: 가끔 사람이 지도에서 잘못된 위치에 놓입니다.

## 소스에서 빌드하기

로컬에서 빌드하려면 Windows에 Rust 툴체인이 필요합니다.

```
cargo test --release
cargo build --release
```

결과물은 `target/release/famtree.exe`입니다. 이 프로젝트는 인터페이스에 [egui/eframe](https://github.com/emilk/egui)을 사용합니다.
